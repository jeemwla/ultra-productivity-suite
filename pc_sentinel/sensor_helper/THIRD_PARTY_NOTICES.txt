PawnIO driver (not included in Ultra Suite)
  PawnIO is a separate program by namazso. Ultra Suite does not include it. When "Full hardware sensors" is chosen
  during setup (or later from PC Sentinel), the sensor helper downloads the official, digitally signed installer from
  https://github.com/namazso/PawnIO.Setup/releases/download/2.2.0/PawnIO_setup.exe, checks its SHA-256
  (1f519a22e47187f70a1379a48ca604981c4fcf694f4e65b734aaa74a9fba3032), and runs it with "-install -silent".
  PawnIO stays installed when Ultra Suite is removed, because other programs may use it. It can be removed from
  Windows Settings > Apps.
  License: GNU General Public License 2.0 or later, with an exception for programs that use PawnIO only through its
  device IO control interface (as the sensor helper does). Details: https://github.com/namazso/PawnIO
  Source code: https://github.com/namazso/PawnIO
  Website: https://pawnio.eu
